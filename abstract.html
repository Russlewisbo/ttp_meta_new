Structured Abstract

Time-to-Positivity and Mortality in Bacteremia: Updated Bayesian Meta-Analysis

Published

May 26, 2026

1 Introduction

Time-to-positivity (TTP) — the interval from blood culture incubation to automated detection of bacterial growth — has been proposed as a prognostic marker in bacteremia. Shorter TTP may reflect higher pathogen burden or virulence, and has been hypothesised to predict mortality. We performed an updated Bayesian random-effects meta-analysis to quantify this association.

2 Methods

Five electronic databases were searched through May 2026 (3,196 unique records after deduplication). Studies were eligible if they reported a quantitative TTP–mortality association in adults with bloodstream infection confirmed by automated blood culture monitoring. Log odds ratios were derived from 2×2 tables or back-calculated from reported estimates. A Bayesian hierarchical model with weakly-informative priors was fitted using Stan; heterogeneity was quantified with τ and I². Risk of bias was assessed with the QUIPS tool.

3 Results

72 mortality effect sizes from 100 studies were pooled (Figure 2). Short TTP was associated with higher mortality (OR = 2.06, 95% CrI 1.67–2.55; P(OR > 1) = 100%). Between-study heterogeneity was substantial (I² = 62%, τ = 0.69; Figure 3). The 95% prediction interval for a new study (0.49–8.69) crossed the null, reflecting heterogeneity. Results were consistent in the 140-study sensitivity pool (OR = 1.92, 95% CrI 1.58–2.35).

Pathogen subgroup analysis. The association between short TTP and mortality was stronger in Gram-negative bacteremia (26 effect sizes; OR = 2.66, 95% CrI 1.72–4.06; P[OR > 1] = 100%) than in Gram-positive bacteremia (13 effect sizes; OR = 1.48, 95% CrI 0.85–2.58; P[OR > 1] = 93%). Pathogen class meta-regression confirmed a lower effect size for Gram-positive relative to Gram-negative organisms (Δ log-OR = -0.50, 95% CrI -1.02–0.02; P[Gram < Gram−] = 97%).

TTP cutpoint meta-regression. A dose-response meta-regression across studies with 2×2-derived effect sizes showed that studies using a higher (less stringent) TTP cutpoint to define ‘short’ reported smaller mortality ORs (Δ log-OR per 10 h increase in cutpoint = -0.355, 95% CrI -0.561–-0.153; multiplicative OR = 0.70; P[slope < 0] = 99.9%).

4 Conclusions

Short TTP is consistently associated with increased mortality risk in bacteremia; however, the effect size is substantially larger for Gram-negative than Gram-positive organisms, and depends strongly on the TTP cutpoint used — ORs fall by approximately 30% per 10-hour increase in the cutpoint threshold. Substantial between-study heterogeneity limits direct generalisation to individual clinical settings. Prospective studies with pre-specified, pathogen-stratified TTP thresholds are needed to establish clinical utility.

### Figure 2 — Forest plot

```{r fig-forest-abstract}
#| label: fig-forest-abstract
#| fig-cap: "Forest plot of OR (short vs long TTP) on mortality — primary pool (n=100 studies). Each row is a single effect size. Pooled Bayesian estimate in red; solid bar = 95% CrI, dashed bar = 95% prediction interval."

fig_h <- max(6, nrow(es_mort) * 0.55 + 2)
knitr::opts_current$set(fig.height = fig_h)

forest_data <- es_mort |>
  arrange(yi) |>
  mutate(
    lbl = paste0(study_id,
                 ifelse(arm_id == "all", "", paste0(" [", arm_id, "]"))),
    lbl = make.unique(lbl, sep = " #"),
    lbl = factor(lbl, levels = lbl),
    or      = exp(yi),
    ci_low  = exp(yi - 1.96 * sei),
    ci_high = exp(yi + 1.96 * sei),
    type = "Study"
  )

pooled_row <- tibble(
  lbl = "POOLED (Bayesian)", or = base_post$median_OR,
  ci_low = base_post$ci_OR[1], ci_high = base_post$ci_OR[2], type = "Pooled"
)
pi_row <- tibble(
  lbl = "POOLED (Bayesian)",
  pi_low  = base_post$pi_OR[1],
  pi_high = base_post$pi_OR[2]
)

forest_data$lbl <- factor(forest_data$lbl,
                           levels = c("POOLED (Bayesian)", levels(forest_data$lbl)))
pooled_row$lbl  <- factor(pooled_row$lbl, levels = levels(forest_data$lbl))
pi_row$lbl      <- factor(pi_row$lbl,     levels = levels(forest_data$lbl))

ggplot(bind_rows(forest_data, pooled_row), aes(x = or, y = lbl, color = type)) +
  geom_vline(xintercept = 1, linetype = "dashed", color = "gray50") +
  geom_point(size = 2.5) +
  geom_errorbar(aes(xmin = pmax(ci_low, 0.05), xmax = pmin(ci_high, 50)),
                width = 0.25, linewidth = 0.7, orientation = "y") +
  geom_errorbar(data = pi_row,
                aes(y = lbl, xmin = pmax(pi_low, 0.05), xmax = pmin(pi_high, 50)),
                width = 0.15, linewidth = 0.7, linetype = "dashed",
                color = "darkred", inherit.aes = FALSE) +
  scale_color_manual(values = c("Study" = "steelblue", "Pooled" = "darkred")) +
  scale_x_log10(breaks = c(0.1, 0.25, 0.5, 1, 2, 4, 8, 16, 32),
                limits  = c(0.05, 50)) +
  labs(subtitle = "Solid red bar = 95% CrI; dashed red bar = 95% prediction interval",
       x = "OR, short vs long TTP (log scale)", y = NULL, color = NULL) +
  theme_minimal(base_size = 9) +
  theme(legend.position  = "bottom",
        axis.text.y      = element_text(size = 7, lineheight = 0.85),
        panel.grid.major.y = element_line(color = "gray92"),
        panel.grid.minor = element_blank())
```
